# lifeboonremake

Симулятор жизни, склеенный с открытым миром: город живёт сам, в него можно
въехать на машине или войти пешком.

Живой мир — **https://depth4.github.io/lifeboonremake/**
(кнопка «за руль» справа вверху, потом «трафик»).

```bash
npm install
npm run dev        # страница на http://localhost:5199
npm test быстро    # все проверки без браузера, полторы минуты
npm test           # то же плюс настоящий браузер
```

## Что внутри

| папка | что там |
|---|---|
| `src/world/` | мир: рельеф, дороги, сеть. Про экран не знает |
| `src/surface/` | поверхность из мира: области, раскрой, краска |
| `src/car/` | машина: паспорт, шина, опора под колесом, физика, руль |
| `src/person/` | человек на своих двоих: тело, шаг, шея, глаза |
| `src/city/` | городская жизнь: трафик, светофоры, пешеходы, нормы, план |
| `tools/` | всё, что запускается из терминала: проверки, снимки, разрезы |
| `docs/` | справочники и журнал решений |

## Как здесь проверяют

Половина списка в `npm test` — **заведомо сломанные случаи, которые обязаны
упасть**. Проверка, которая ни разу не падала, — не проверка: пока не показано,
что она ловит поломку, зелёная галочка ничего не значит. Заведомо сломанный
случай, который прошёл, — провал всей проверки, а не мелочь.

Мир считается **без экрана**: `npm run traffic`, `npm run drive`, `npm run plan`
гоняют город и машину в терминале. Это не удобство, а требование — впереди
мультиплеер, где мир живёт на сервере.

Снимок делается **оттуда, где стоит игрок**. Вид сверху показывает, что вещи
расставлены; он не показывает, как это выглядит.

## Правила работы

`CLAUDE.md` — как здесь принимают решения и что считается «готово».
`STATE.md` — где проект сейчас: что работает, что следующее, что не трогать.
`docs/decisions.md` — журнал решений, ограничивающих будущее.
