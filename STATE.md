## Назначение папок

- `src/world/` — мир: рельеф, дороги. Ничего про экран, считается без браузера.
- `src/` (surface, render, main, demo) — поверхность из мира, показ, склейка, данные для шага 1.
- `src/types/` — описания типов для сторонних библиотек без своих типов.
- `tools/` — проверка мира, снимок экрана, сборка самодостаточной страницы.
  Всё запускается из терминала.
- `shots/` — снимки экрана, не хранятся в репозитории.

## Куда идём (видение Алекса)

Симулятор жизни, склеенный с открытым миром в духе GTA/SAMP. Одновременно:

- **Текстовый симулятор жизни** — жизнь персонажа, работа, деньги, отношения.
- **Открытый мир** — за руль может сесть человек, которому симулятор жизни
  не интересен: покататься, поработать таксистом, погонять.
- **Персонаж** — ходьба, бег, прыжки, взаимодействие с миром.
- **Интерьеры** — в здания можно входить. Из окна виден настоящий город,
  который живёт своей жизнью. Ключевое для ощущения присутствия:
  окно — доказательство, что мир существует без игрока.
- **Мультиплеер** в будущем: серверы, общий мир. Отсюда требование, чтобы мир
  считался без экрана.
- Возможно животные.
- Правдоподобный город — в перспективе на основе реальных карт (решение 003).

**Текстовый симулятор и открытый мир — не два проекта и не два режима.**
Это два окна в один и тот же мир и две степени приближения к нему.

**Первый играбельный кусок:** проехать на машине по дороге в маленьком
рукотворном квартале.

## Инварианты

1. Метр — единственная единица измерения. Мир живёт рядом с нулём.
   Игровой сетки нет.
2. Земля — одна поверхность. Дорога — её участок с другим покрытием,
   а не объект поверх земли.
3. Дорожная сеть — граф. Видимая геометрия вычисляется из графа,
   а не хранится отдельно.
4. Мир не знает, что его рисуют. Считается без экрана.
5. «Существует» и «видно» — разные вещи. Мир существует весь;
   рисуется только то, что видно камере.
6. Мир не знает, откуда взялись данные. Импортёр выдаёт корректный мир
   или не выдаёт ничего.

Пункты 1, 2, 4 проверены кодом. Пункты 3, 5, 6 пока только объявлены —
подсистем, которые их нарушали бы, ещё нет.

## Чего не трогаем и почему

- Реальные данные карт — по решению 003, до готовности игрового мира.
- Физический движок — подключается вместе с первой машиной, не раньше.
- Перекрёстки — самое трудное место темы, отдельный осознанный шаг.
- Переход «земля ↔ мост» — второе трудное место, отдельный шаг.

## Рельеф — ВРЕМЕННАЯ ЗАГЛУШКА, не система

`src/world/terrain.ts` — три строчки арифметики (уклон плюс синусоиды).
Это не система рельефа: рельеф нигде не хранится, не редактируется,
не подгружается. Заглушка нужна была ровно затем, чтобы земля не была плоской,
иначе проверка «дорога врезана, а не лежит сверху» не смогла бы упасть.

**Устройство рельефа — нерешённый совместный вопрос.** Как он хранится,
как правится, как приходит из реальных карт — ничего из этого не решено.
Заменяется без последствий: единственная точка, через которую рельеф касается
остального проекта, — функция `groundHeightAt` в `src/world/world.ts`.
Что внутри неё — сменится; сама она останется.

## Известные упрощения шага 1

Названы вслух, чтобы не выдавать за готовое:

- Бордюра нет: тротуар лежит вровень с проезжей частью.
- Разметка сплошная, прерывистой нет.
- Дорога одна, перекрёстков нет — стыковка дорог не проверялась.
- Высота дороги = сглаженный рельеф под ней. Явных высот (мост, тоннель)
  пока нет, хотя устройство данных их допускает.
